# R6ConfigBridge

Windows 本地彩虹六号配置迁移工具：国际服 ⇄ 腾讯 WeGame 国服。MVP 0.2，非官方项目，与 Ubisoft／腾讯无隶属或背书关系。

## 下载与运行

从本仓库 Releases 下载 Windows x64 ZIP，解压后双击 `R6ConfigBridge.exe`。也可使用仓库 `dist/windows/R6ConfigBridge.exe`。

C# + WinForms + .NET Framework 4.x，不是 WinUI 3 或 Native AOT。没有浏览器外壳、开机启动项或后台服务；关闭窗口即退出。当前 UI 改进版 EXE 为 69,120 字节；运行时内存与完整运行环境成本尚未测量，不能以 EXE 大小代替内存数据。

## 用法

1. 点击“扫描已安装游戏”，分别检查国服（左）与国际服（右）的安装线索及配置。支持自动发现标准 Documents 路径及手动选择 GameSettings.ini；多账号不猜选。仅发现一服时也显示该服值，另一侧明确标记未加载，两份配置加载前不能迁移。
2. 国服值在左、国际服值在右；配置项默认用中文名称，账号用序号区分，不暴露账号目录／配置键。勾选“技术详情”可查看原始键、路径及内部只读行，切换不会丢失勾选；真实设置值保持原样，不猜测枚举含义。可按中文名称搜索或仅显示差异。
3. 选择迁移方向，预览所有所选修改。筛选隐藏的勾选项也包含在选择中。
4. 正常退出两服后确认应用，工具先备份再写入并回读校验，不会替用户关闭游戏。
5. 启动目标服核对效果，退出重启后检查是否保留；云同步可能覆盖本地结果，工具不更改启动器同步选项。

备份保存在 EXE 旁 `backups/`，保留 `.ini` 和同名 `.ini.xml`；恢复前也备份当前状态。若配置在预览后变化，或迁移后又被游戏修改，工具拒绝直接覆盖。

## 能力及未完成项目

- 已在一台 Windows 实机加载两份各 158 字段的配置，其中 132 项在迁移白名单。
- 涵盖鼠标／倍率灵敏度、按住或切换行为、手柄、显示、画质、声音及辅助功能；内部硬件、设备 ID、网络字段不默认迁移。
- **具体动作键位、鼠标侧键绑定尚未实现。** INI 的按住／切换行为不等于完整键位。
- 核心 14 项及 UI 162 项检查通过；真实配置副本的双向迁移、非白名单保留和逐字节恢复通过。
- **尚未对真实游戏设置执行迁移，也未验收游戏内生效、重启保留或云同步行为。** 不保证两服同名枚举的语义完全相同。
- 尚未验证所有版本、显示缩放、多账号与不同编码。UTF-16 配置不支持，重复字段拒绝；不提供任意 Unicode 值编辑。
- 程序未签名，不保证反作弊兼容或零封号风险。不注入游戏、不读写游戏内存、不修改游戏程序。

## 源码与构建

- `App.cs`：WinForms 界面及集成 smoke 模式。
- `UiText.cs`：界面中文名称映射；不改变底层字段 ID。
- `Discovery.cs`：有界的只读配置／平台安装记录扫描。
- `UiTests.cs`：WinForms 反射与隔离夹具验收（162 项检查）。
- `Core.cs`：INI 解析、白名单、备份／应用／恢复。
- `Tests.cs`：核心行为测试。
- `assets/`：原创双向箭头图标（SVG／PNG／多尺寸 ICO）。
- `build.cmd`：先构建并运行测试，再编译 Windows x64 EXE，内嵌图标。
- `dist/windows/`：已验证的 Windows 编译产物快照。

Windows 项目目录运行：

```bat
build.cmd
```

使用系统 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，无 NuGet 依赖。生成根目录 Tests.exe、UiTests.exe 与 R6ConfigBridge.exe；不自动更新 dist 快照。macOS 不能原生构建／运行本 WinForms 程序。

副本 smoke 测试：

```bat
R6ConfigBridge.exe --smoke C:\R6ConfigBridgeTest\smoke-new
```

仅使用新的专用目录。该模式读取真实配置，但只向测试副本写入；会保留私人样本、备份和窗口截图，不要提交它们。不代表用户桌面交互或游戏内验收已通过。

## 安装扫描的范围与限制

- 扫描 Windows Known Documents 下两服已知 `My Games` 账号目录（单层、最多 256 个），发现 `GameSettings.ini` 后加载可用配置；保留用户仍存在的手动选择，多账号不猜选。
- 只读查询当前用户／本机 32 位和 64 位卸载记录、Ubisoft 1843 安装项，以及 Steam 注册表路径、`libraryfolders.vdf` 和游戏 359550 的 `appmanifest`。有平台记录且已知游戏 EXE 存在才显示检测到安装；仅有记录显示候选，不能凭文件夹名称断言安装。
- 各侧分别显示“安装／候选”“发现配置／未发现配置”“扫描错误”。没有配置不等于没安装：游戏可能尚未启动，或目录不在扫描范围。WeGame 私有元数据尚未解析，只使用可识别的卸载记录及已知配置位置。
- 扫描在后台线程执行，不全盘递归，不启动／安装游戏，不联网。库最多 32 个、单个清单最多 1 MiB、每组卸载记录最多 4096 项；非标准路径继续用手动选择。
- EXE 被用户窗口锁定时可使用 `set R6_OUTPUT=R6ConfigBridge-v0.2.exe` 后运行 `build.cmd`，不强制结束用户进程。
- `--smoke` 使用独立测试互斥锁，可与用户打开的窗口并存；仅对测试副本迁移／恢复。离屏截图不等于真实桌面人工验收，原生下拉框在离屏捕获中可能空白。
